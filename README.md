# 🗼 Tower of Hanoi in C++

A C++ implementation of the classic **Tower of Hanoi** puzzle featuring **both iterative and recursive approaches**.

This project was created to compare two different algorithmic strategies for solving the same problem while strengthening my understanding of recursion, stack operations, and algorithm design.

---

## 📌 Project Overview

The repository contains two independent implementations:

* **Iterative Solution** – Solves the puzzle without recursion by repeatedly performing legal moves between towers.
* **Recursive Solution** – Implements the classic divide-and-conquer recursive algorithm.

Both implementations are written in C++ and organized separately for easier comparison.

## 🚀 Features

### Iterative Implementation

* Solves the puzzle without recursion.
* Uses legal move logic between towers.
* Demonstrates stack manipulation and algorithm simulation.

### Recursive Implementation

* Uses the classic recursive Tower of Hanoi algorithm.
* Demonstrates divide-and-conquer problem solving.
* Illustrates recursive function calls and the call stack.
